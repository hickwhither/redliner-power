# Redliner Power

## Import v1

```lua
loadstring(game:HttpGet("https://github.com/hickwhither/redliner-power/releases/download/v1/redliner-v1.lua"))()
```

[Download redliner-v1.lua](https://github.com/hickwhither/redliner-power/releases/download/v1/redliner-v1.lua) | [Release v1](https://github.com/hickwhither/redliner-power/releases/tag/v1)

The release bundles all project modules into one file. Fluent 1.1.0 loads online, so internet access is required.
A compatible Roblox client needs `Drawing`, `loadstring`, HTTP access, and permission to use `CoreGui`.

## Controls

- Fullbright, NoFog, AutoAim, and ESP have toggles and configurable keybinds.
- AutoAim defaults to `V`.
- Backquote hides or shows the window.
- STOP / Unload stops the project and closes the UI.
